# Sample Documents

This directory contains **synthetic** sample documents for testing and development.

> ⚠️ **Never commit real company documents to this repository.**

## Included Files

| File | Format | Purpose |
|------|--------|---------|
| `sample_hr_policy.txt` | TXT | Basic HR policy for testing text extraction |
| `sample_it_guidelines.txt` | TXT | IT security guidelines for multi-doc testing |

## Creating PDF and DOCX Test Files

Run the generator script to create PDF and DOCX test documents:

```bash
python data/sample_docs/generate_samples.py
```
